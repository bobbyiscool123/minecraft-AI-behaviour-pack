# Debug Commands

- `/function wl/debug/on` — enable debug and tag caller as viewer.
- `/function wl/debug/off` — disable debug.
- `/function wl/debug/status` — show init/clock/anchor counters.
- `/function wl/debug/place` — print nearest place DNA + stage values.
- `/function wl/debug/anchor` — print nearest anchor status/id.
- `/function wl/debug/advance_arc` — increment nearest arc stage.
- `/function wl/debug/reset_nearby_place` — clear nearby place arc/history/cooldown.
- `/function wl/debug/clear_events` — clear pending event/scenelet/after flags.
- `/function wl/debug/cooldowns_clear` — clear all cooldown counters.
- `/function wl/debug/failsafe` — force failsafe cleanup.
