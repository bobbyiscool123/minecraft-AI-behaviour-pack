# WorldLore Bedrock Archive Engine — System Card

## What this is
A **behavior-pack-only** lore illusion engine for Minecraft Bedrock. It relies on scoreboards, tags, deterministic generated functions, and low-frequency runtime phases to simulate persistent place memory.

## What this is not
- No backend service
- No online LLM or API calls
- No custom resource pack requirements
- No Java/Fabric/Forge/Paper style modding

## PR1 working slice
- Village-like anchor creation and persistence
- Place DNA assignment (hard + soft + memory state)
- Low-frequency runtime scheduler (100/200/300/400/500)
- Arc scaffolding with bee/witch, pillager, and portal pressure flows
- Scenelets, messages, and safe aftermath examples
- Debug + forced scenario functions
- Deterministic tiny generator + validation/build scripts
